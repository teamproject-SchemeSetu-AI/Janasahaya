## Important GitHub workflow
1. Do NOT run `git init` in this task folder and do NOT push this partial folder as a separate project.
2. The team leader should first push the complete original JanaSahay project to the shared GitHub repository.
3. Each member should clone that shared repository using their own GitHub account.
4. Create a personal branch, edit only the assigned files, then commit and push that branch.
5. Create a Pull Request to merge the changes.

These folders are task packs, not complete runnable copies of the whole app. Keep the original folder structure when copying/editing files in the shared repository.
